# 原神 祈願録（使ってないキャラを使う機会を作るサイト）

原神でせっかく手に入れたのに使っていないキャラを、もう一度使う「機会」を作るためのWebサイト。
友達と一緒に、一定期間ごとに使うキャラを決めて遊ぶための仕組み。

## 特徴
- 所持キャラを国（モンド／璃月／稲妻／スメール／フォンテーヌ／ナタ／ナドクライ ほか）ごとに管理
- 使うキャラを抽選して、その期間に使うメンバーを決められる
- データはブラウザ内に保存（サーバー不要の静的サイト）

## 構成
- `index.html` … サイト本体（キャラデータも内蔵）
- 各国フォルダ（例：`モンド/`）… キャラの立ち絵画像

## 公開方法
GitHub Pages で公開できます。手順は別ファイル「公開手順」を参照。
